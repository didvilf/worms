# Fish Isles

3D-игра про рыбалку на островах (Three.js, один файл `index.html`).

## Запуск на Render через GitHub
1. Создай репозиторий на GitHub и загрузи в него все файлы из этой папки (`index.html`, `render.yaml`, `README.md`).
2. На render.com: **New → Blueprint** (или **New → Static Site**) и выбери репозиторий.
   - Для Static Site: Build Command оставь пустым, Publish Directory = `.`
3. Нажми Deploy. Сайт откроется по адресу вида `https://fish-isles.onrender.com`.

Локально: открой `index.html` в браузере (нужен интернет для загрузки Three.js с cdnjs).

## Управление
WASD — ходьба, Shift — бег, F — рыбалка, E — действие, Пробел/клик — удар, V — первое лицо, Esc — настройки, мышь/стрелки — камера.
